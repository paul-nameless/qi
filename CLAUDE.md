# qi

Minimal Go coding agent for the terminal.

## Layout
- `main.go` only `var version` (stamped by goreleaser's `-X main.version`) and `os.Exit(app.Main(os.Args[1:], version))`
- `internal/app` everything else, exporting only `Main`: `cli.go` the flags on a `flag.FlagSet`, usage, `-version`, `-show`, `-check-config`, exit codes; `version.go` the stamped version, else one from build info; `run.go` config, provider and agent wiring shared by both modes (`buildAgent`, `newProvider`, `resolveConfig`, `loadHooks`, `submitPrompt`), `headless.go` `-q`/stdin mode (`-json` tees every session entry to stdout via `session.CreateOptions.Tee`, the same bytes as the file), `repl.go` interactive loop, `commands.go` slash commands and image attachment, `picker.go` the `/` picker (runs the `picker` config command, fzf by default), `filelist.go` the `@` file list (git files first, then a capped breadth-first walk), `external.go` the shared contract for external UI tools (`toolAvailable`, `expandTool` turns placeholders into quote-aware `$QI_*` env references so values never become shell code, `choose`, `runQuiet`, `runTTY` via `Editor.RunTTY`), `sessions.go` `/resume`, `-r`, `-show`, `render.go` renders a session as text (plain for `-show`, colored with `ui.Markdown` for the `/history` pager)
- `internal/llm` canonical message types, SSE, provider adapters, `retry.go` typed errors and `Retryable` (request layer retries pre-response failures, `agent.stream` mid-stream ones; `llm.Sleep` is the injectable wait) (`openai.go` chat completions incl. OpenRouter, `responses.go` the OpenAI Responses API (stateless: `store: false`, encrypted reasoning items replayed for the same model), `anthropic.go`)
- `internal/agent` turn loop (`agent.New(Options)`, state unexported behind accessors: `mu` guards `live` (config, provider, session, system prompt, steering queue, context tokens) and is never held across I/O; `busy` is held for a whole turn or compaction and guards `conv` (messages, registry, turn state); writers that must not land mid-turn take `busy` then `mu`), `frontmatter.go` minimal SKILL.md frontmatter parser (top-level scalars only, whitespace-normalised), `builtin.go` embedded built-in skills (`builtin/qi-config`) written with the schema to the user cache dir and listed in the static prompt, compaction (`compact.go`: unchanged-history summary request, verbatim tail without reasoning between turns, summary-only mid-turn, overflow retry, thrash pause), steering queue, `images.go` evicts the oldest images past 100 or 24 MB (never on a normal request), system prompt (`prompt.go` records named sections for `/context`, `context.go` the breakdown), skills, subagent runner (runs `qi -q … -json` with `QI_PARENT_SESSION` set; the child records it as `parent_session` in its meta and writes to `subagents/`, shows tool-call labels as progress, answers with the last assistant text, keeps a stderr tail for errors), hooks (`hooks.go`: hook files parsed once; a missing file is skipped, an unreadable or malformed one stops startup; hooks of one event run in parallel and are waited for, except `"async": true` ones, which start detached with no output pipes and are never waited for; `async` is part of the trust fingerprint, and a command listed both ways runs blocking), project trust (`trust.go`: the trust file pins each trusted dir to a fingerprint of its project hooks)
- `internal/config` JSON config with providers and profiles (`decode.go` strict, case-sensitive decoding with encoding/json/v2 and file/key errors; `validate.go` the schema's enums, minimums and required fields; `schema.json` the embedded JSON Schema, kept in sync with the structs by a test); `mcp.go` the tool globs and the per-profile `mcp` merge by server name (null removes a global server), checked after merging; `limits.go` parses `compact_at`/`compact_idle_at` (tokens or %) and resolves them against `context_window` or a small model table
- `internal/tools` registry with parallel execution, read/write/edit/bash/subagent, read-only allowlist (`readonly.go`: builtins get no `$`/backtick arguments, assigning builtins are refused, go subcommands have a flag allowlist; the sandboxes also deny network), `files.go` tracks file mtimes so write refuses to overwrite a file changed since the model last read or wrote it (edit needs no guard: it only replaces exact text); it also snapshots files the model read or wrote, and the agent sends a diff of any outside change with the next tool results or user message; `image.go` scales images from read, paste and MCP to ≤1568px with a stdlib area-average resize, `read` takes `crop` for full-resolution regions; `jobs.go` background bash (`background`/`daemon`): output straight to a file in the spill dir, a `<background-job>` notice when the job's shell exits (none when killed); processes left in its group stay listed and killable until the job's timeout, the `jobs` tool lists or kills; the agent turn stays open while a non-daemon job runs (woken by its exit, queued input or Ctrl-C, which only stops the wait), notices from between turns join the next user message, and all jobs are killed on /clear, session load and exit
- `internal/ui` termios, key decoder, line editor, printer with status line (the prompt and the steering draft are multi-row `Frame`s; the printer remembers the rows it drew and clears them, recounting them after a resize reflow), `layout.go` the pure input layout (rows with soft wrap, cursor row and column, scroll window, up/down between rows), `crash.go` (`OnCrash` cleanups, `defer ui.CleanupOnPanic()` in goroutines restores the terminal before re-panicking), `markdown.go` streaming markdown styling of answers (TTY only; `table.go` aligns tables, `width.go` display width, `image.go` kitty graphics: after a turn the repl passes the final answer to `Printer.Images`, which draws existing image files whose paths appear in it, when `KittyGraphics` detects Ghostty/kitty outside tmux)
- `internal/session` append-only JSONL sessions (an open session file holds an exclusive flock, `lock.go`; `Tee` streams to stdout for `-json`); `Load`/`Entries` are read-only (`Open` repairs the file for appending), `List` summarizes a directory's sessions
- `internal/mcp` stdio MCP client (lazy start, tool search, per-server `tools`/`exclude_tools` globs from `config/mcp.go` enforced in the Manager: hidden tools never listed or called); exposed as `tool_search`/`mcp_call` in `internal/tools/mcp.go` (compact listing past 10 tools, never cut by the output cap), `/mcp` in `internal/app/commands.go`; subagents get the parent's `mcp` as JSON in `QI_MCP` (unset on read, replaces the config's); `mcptest` is the fake server the tests run
- `internal/proc` child processes in their own session (`proc.Session`: bash, hooks, subagents, MCP) or process group (`proc.Group`: quiet external tools, which may still need the terminal); one kill policy: SIGTERM the group, SIGKILL it after a grace period (2s, subagents 5s, MCP close 1s), `WaitDelay` grace+1s; `Stop` escalates synchronously and `proc.Settle` waits (bounded) for escalations of cancelled commands before qi exits; TTY tools (picker, pager, `$EDITOR`) stay in the foreground group
- `internal/imgutil` `ToRGBA` and the area-average `Resize`, shared by `tools/image.go` and `ui/image.go`
- `internal/testenv` shared `TestMain` (`testenv.Run`) for config, agent, app and tools: clears `QI_*`, `GIT_*`, API keys and `PAGER`, points `QI_CONFIG_DIR`/`QI_SESSION_DIR` at a temp dir; use it in new test packages

## Commands
- Build: `go build -o qi .`
- Test: `go test ./...`
- Format, vet, lint, test: `task ch` (lint runs golangci-lint v2.15.0 via `go run`, same as CI)
- Headless smoke test: `./qi -q "prompt" </dev/null` (uses `~/.config/qi/config.json`); `./qi -check-config [-config f] [-p name]` validates config without calling the API; to trigger compaction, run with `-config` pointing at a copy of the config with a small `compact_at` (e.g. `20000` or `1.5%`); the system prompt and tools alone are ~5k tokens, so lower values pause auto-compaction
- UI testing: run in tmux (`tmux new-session -d -s ai -x 120 -y 40 './qi'`, then `send-keys`/`capture-pane`); shift+tab is `$'\e[Z'`, bracketed paste via `tmux paste-buffer -p`

## Rules
- Keep the request prefix byte-stable for prompt caching: no timestamps in the system prompt, fixed tool list (read-only is enforced at execution, not by removing tools), deterministic JSON. The system prompt is two cached blocks: the static part (base prompt, global instruction files, global skills) must not depend on the directory, so every session shares it; cwd, date and project files go in the second block
- Every `tool_use` in the log needs a `tool_result`; append assistant messages only when the stream completes
- Compaction must not rewrite the history it sends (cache); messages kept after a summary carry no reasoning blocks (Claude 5.x rejects replayed thinking after a changed prefix)
- Never `MakeRaw` the terminal: it clears OPOST and output staircases; `ui.Terminal` keeps ISIG so ctrl+c is SIGINT
- No code comments
- Small, focused functions; check errors and return meaningful messages
- External UI tools (picker, pager, notifier, ...) are shell-string config keys with `{placeholders}`, never hard dependencies, documented in readme "External tools". Defaults live in `config.toolDefaults`; add new keys to `repl.toolKeys` so `/config` lists them
- Only the user's input and the model's answer print in normal color; tool lines, reasoning and info are dim
